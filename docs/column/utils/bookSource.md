## 三、保姆级导入教程（新手也能一键搞定）

书源和APP都准备好后，接下来就是关键的导入步骤，两款APP的导入方法略有不同，详细步骤如下，跟着操作，1分钟就能完成！

### 1. 开源阅读APP导入步骤

1. 打开已安装好的开源阅读APP，进入首页后，点击底部导航栏的【书源】选项；
2. 进入书源页面后，点击右上角的【菜单】按钮（三个点的图标），在弹出的菜单中选择【在线导入】；
3. 将之前复制的任意一条书源链接，粘贴到输入框中，点击【确定】；
4. 等待系统加载书源，加载完成后会提示“导入成功”，此时书源会自动启用；
5. 返回首页，点击顶部搜索框，输入想看的小说名称，就能搜到海量资源啦！

### 2. 笔趣阁APP导入步骤

1. 打开笔趣阁APP，进入首页后，点击底部导航栏的【我的】选项，进入个人中心；
2. 在个人中心页面，找到【书源管理】选项，点击进入；
3. 点击页面顶部的【在线导入】按钮，将复制的书源链接粘贴到输入框中，点击【确认导入】；
4. 导入完成后，可在书源列表中看到已导入的书源，手动勾选需要启用的书源；
5. 返回首页，搜索小说即可使用，还能根据自己的喜好，禁用不需要的书源。
